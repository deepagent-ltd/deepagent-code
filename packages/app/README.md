# DeepAgent Code GUI

The shared SolidJS interface for DeepAgent Code's web app and Electron desktop renderer. It presents projects, sessions, streaming agent output, tools, settings, and IM through the [agent server](../deepagent-code/README.md).

The current source release line and package version are **2.0.4**. This package builds the GUI; the [desktop package](../desktop/README.md) owns Electron integration and installers. See the [repository README](../../README.md) for the full product introduction.

## Stack

- **UI:** SolidJS, Vite, and shared `@deepagent-code/ui` components.
- **Backend:** the DAC server, accessed through the JavaScript SDK and streaming events.
- **Web build:** `dist/`, generated by this package's Vite build.
- **Desktop renderer:** bundled by Electron Vite as part of the desktop build.

## Development

Use the Bun version declared in the root `package.json`. Install dependencies from the repository root:

```bash
bun install
```

Run the backend and GUI in separate terminals, both from the repository root:

```bash
# Terminal 1: local agent server
bun run dev serve --port 4096

# Terminal 2: local GUI with hot reload
bun run dev:web -- --port 4444
```

Open `http://localhost:4444`. The development GUI connects to `http://localhost:4096` by default. `VITE_DEEPAGENT_CODE_SERVER_HOST` and `VITE_DEEPAGENT_CODE_SERVER_PORT` can select a different backend. Root `bun dev` starts the TUI; `bun run dev:desktop` starts Electron.

## Build

From `packages/app`:

```bash
bun run build
bun run serve
```

The output in `dist/` can be hosted as a static GUI, but it still needs a reachable DAC backend. Model credentials, session execution, and tool permissions belong to that backend. Desktop packaging uses its own build pipeline.

## Validate changes

From `packages/app`:

```bash
bun typecheck
bun run test:unit
bun run test:components
bunx playwright install chromium
bun run test:e2e:local
bun run test:e2e:local -- --grep "settings"
```

`test:unit` includes `src/` and standalone `test/` tests; component tests have a separate Vitest runner. Playwright starts the Vite server and expects a DAC backend at `127.0.0.1:4096` by default. Start or select the intended test backend before running E2E tests.

Playwright options:

- `PLAYWRIGHT_SERVER_HOST` / `PLAYWRIGHT_SERVER_PORT` (backend address, default: `127.0.0.1:4096`)
- `PLAYWRIGHT_PORT` (Vite dev server port, default: `3000`)
- `PLAYWRIGHT_BASE_URL` (override base URL, default: `http://127.0.0.1:<PLAYWRIGHT_PORT>`)

`bun run test:e2e:im-real` selects the current IM `/dac` integration test against an explicitly configured, already running desktop. It requires its dedicated test environment and can execute real agent requests; it is separate from the default unit and component suites.
